Tiny Monsters generates a unique creature every refresh using only internal procedural drawing.

No external APIs, no AI, everything is built using simple shapes and randomness, now guided by monster archetypes.

Available archetypes: Zombie, Werewolf, Octopus, Dragon, Spider, Dinosaur, Cthulhu, Ghost, plus a fully Random Monster mode.

The default behavior is Random Archetype or Random Monster, which randomly chooses between the archetypes above and a fully free-form random monster.
