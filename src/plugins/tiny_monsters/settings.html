Tiny Monsters generates a unique creature every refresh using only internal procedural drawing.

No external APIs, no AI, everything is built using simple shapes and randomness.

Each monster is composed from basic geometric elements like circles, lines and polygons, combined in a controlled way to create playful and cohesive characters.

Every refresh produces a completely new monster along with a randomly generated name, making each render feel fresh and unique while staying lightweight and fast for e-ink displays.
